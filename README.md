# 🚀 Smart Student AI Learning Hub

An AI-inspired, interactive student learning portal designed for Class 9th students to revise subjects, attempt quizzes, track academic progress, and boost productivity using built-in study tools.

![Project Status](https://img.shields.io/badge/Status-In_Development-brightgreen)
![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20JS-blue)

## ✨ Key Features
- **Futuristic Glassmorphism UI**: High-tech student dashboard layout.
- **Smart Quiz Engine**: Subject & chapter-wise MCQs with instant scoring.
- **Progress Tracker**: Visual indicators showing topic completion and subject mastery.
- **Built-in Study Timer**: Integrated Pomodoro timer for revision management.
- **Achievement System**: Gamified badges unlocked based on quiz performance.

## 🛠️ Tech Stack
- **HTML5**: Semantic layout.
- **CSS3**: CSS Grid, Flexbox, Custom Variables, Dark Futuristic Theme.
- **JavaScript (ES6)**: Dynamic rendering, local storage state persistence.
